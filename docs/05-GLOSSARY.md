# Glossary

Simple meanings of the terms used in these documents.

| Term | Simple meaning |
| --- | --- |
| TapeOut | A system on the blockchain where people build small logic circuits and can also host websites. |
| X Layer | The blockchain this project targets. It is run by OKX. Its chain ID is 196. |
| BNB Chain | Another blockchain where TapeOut also runs. Chain ID 56. |
| On-chain | Stored on the blockchain, not on a normal server. |
| DeWEB | TapeOut's name for websites stored on-chain. |
| TapeOut site | A website whose files are stored on-chain. |
| Circuit | A small piece of logic created on TapeOut. Each circuit can own one site space. |
| Processor | A group that circuits belong to. Each processor has a number. |
| Site space (container) | The on-chain account that belongs to a circuit and holds its website files. |
| Site store (SiteRegistry) | The on-chain record that keeps every site's files. |
| TapeKit | TapeOut's open-source toolkit for reading and showing on-chain sites. |
| Reader (kernel) | The part of TapeKit that finds a site, downloads its files and checks them. |
| Gateway | A normal web address that lets ordinary browsers open on-chain sites. |
| Fingerprint (hash) | A short code calculated from a file. If the file changes, the fingerprint changes. |
| Integrity check | Confirming a file matches its fingerprint, meaning it was not altered. |
| Wallet | The app a person uses to hold crypto and approve actions. |
| Secret recovery phrase | The 12 or 24 words that give full control of a wallet. Never shared. |
| Private key | The secret code that controls a wallet. Never shared. |
| Token approval | Permission a user gives a site to move their tokens. |
| Unlimited approval | Permission to move any amount, with no cap. |
| Signing | The wallet confirming a message or action on the user's behalf. |
| Scrambled code (obfuscation) | Code made hard to read on purpose. |
| Compressed code (minified) | Code shortened to load faster. Normal and not a danger sign. |
| Outside server | Any server that is not part of TapeOut or the blockchain. |
| Live socket connection | A constant two-way connection to a server (WebSocket or WebRTC). |
| Connection (RPC) | The address a program uses to talk to the blockchain. |
| Past records (logs, events) | The history of things that happened on-chain. Not every connection returns them. |
| Sign (in this product) | One danger clue found in a site's files. |
| Check | The rule that looks for one kind of sign. |
| Scan | One full run of finding sites, reading files and running checks. |
| Hand review | A person looking at a site to confirm or correct the result. |
| Override | A colour set by hand after a review, with a note. |
| Badge | A small image a site owner can show to display their rating. |
| DeWEB edition | The version of this product that is itself stored on TapeOut. |
| OKB | The coin used to pay fees on X Layer. |
| Fully on-chain | A site that loads nothing from outside servers. |
